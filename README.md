# Karabiner-Elements

🪝 [Karabiner-Elements](https://karabiner-elements.pqrs.org) complex-modification rules for macOS.


## Install

Karabiner-Elements loads complex-modification rules from `~/.config/karabiner/assets/complex_modifications/`. Clone the repo into the path.

```bash
git clone https://github.com/rajatdiptabiswas/karabiner-elements.git ~/.config/karabiner/assets/complex_modifications
```

Open **Karabiner-Elements → Complex Modifications → Add rule** and enable the required rules.

## Update

```bash
git -C ~/.config/karabiner/assets/complex_modifications pull
```

## Rules

| Rule | Behavior |
| --- | --- |
| `caps_lock-to-ctrl` | Tap Caps Lock twice for Caps Lock; hold for Control. |
| `spacebar-to-alt` | Tap Spacebar for Space; hold for Left Alt. |
